# 운영 전 개인정보·아동 이용 점검표

- 문제 사진에 얼굴, 이름, 학교명, 연락처가 나오지 않도록 가입 및 촬영 화면에서 안내합니다.
- 앱은 문제 사진을 Firestore나 기기 저장소에 별도로 저장하지 않습니다.
- 사진은 풀이를 위해 Google Gemini API에, 문제의 검색용 문장은 Pinecone API에 전송됩니다.
- 만 14세 미만 이용자는 보호자 동의를 확인한 뒤 관리자가 승인합니다.
- 실제 운영 전 서비스 이용약관과 개인정보 처리방침을 별도로 작성하고 보호자에게 고지하세요.
- 탈퇴 요청이 오면 Firebase Authentication 계정과 `users/{uid}` 아래 기록을 관리자가 직접 삭제해야 합니다.
- Gemini·Pinecone 키는 APK나 GitHub에 넣지 않고 Cloudflare Worker Secret으로만 관리하며, 사용량 제한과 정기 교체를 적용하세요.
- 저작권 문제가 없는 자체 제작 문제 또는 정당하게 이용 허락을 받은 기출 자료만 Pinecone에 등록하세요.

이 문서는 개발 점검표이며 법률 자문을 대신하지 않습니다.
